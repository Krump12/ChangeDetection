# Data Model: Remote Sensing Change Detection Model

## TemporalImagePair

Represents one matched before/after remote sensing sample.

**Fields**

- `filename`: Shared source filename or normalized stem used for pairing.
- `split`: One of `train`, `val`, or `test`.
- `image_a_path`: Path to the before-time image.
- `image_b_path`: Path to the after-time image.
- `width`: Expected value `128`.
- `height`: Expected value `128`.
- `format`: Supported image format, PNG or JPG.

**Relationships**

- Has one `ChangeLabelMask` for `train` and `val` splits.
- Has zero labels for `test` split.
- Produces zero or one `PredictionMask` during prediction.

**Validation Rules**

- A and B files must both exist.
- A and B must be readable images.
- A and B dimensions must match 128x128.
- Pairing must be based on matching filenames, not directory order alone.

## ChangeLabelMask

Represents the supervised binary target for a train or validation pair.

**Fields**

- `filename`: Must correspond to the temporal pair filename.
- `mask_path`: Path to the label file.
- `width`: Expected value `128`.
- `height`: Expected value `128`.
- `binary_values`: Normalized non-change/change values.

**Relationships**

- Belongs to exactly one `TemporalImagePair` in `train` or `val`.

**Validation Rules**

- Label file must exist for every train and validation pair.
- Label must be readable.
- Label dimensions must match 128x128.
- Grayscale or color labels must normalize deterministically into binary non-change/change values.

## PredictionMask

Represents the generated output for one test pair.

**Fields**

- `source_filename`: Filename corresponding to the test pair.
- `output_path`: Path under the configured prediction mask directory.
- `threshold`: Probability cutoff used to convert scores into binary output.
- `width`: Expected value `128`.
- `height`: Expected value `128`.
- `pixel_values`: Black for non-change and white for change.

**Relationships**

- Belongs to exactly one `TemporalImagePair` from the `test` split.
- Is generated by one `ModelArtifact`.

**Validation Rules**

- Output filename must correspond to the input pair.
- Output format must be PNG.
- Output must be single-channel or semantically single-channel.
- Output must contain only binary values.

## ModelArtifact

Represents a saved model selected during training.

**Fields**

- `checkpoint_path`: Location under the configured checkpoints directory.
- `config_reference`: Configuration used for training.
- `selected_epoch`: Epoch associated with the saved artifact.
- `selection_signal`: Simple validation loss or configured best-model signal.

**Relationships**

- Created by the training workflow.
- Consumed by validation and prediction workflows.

**Validation Rules**

- Checkpoint path must exist before validation or prediction starts.
- Artifact must be compatible with the configured model definition.

## Configuration

Represents user-adjustable settings for local workflows.

**Fields**

- `train_a_dir`, `train_b_dir`, `train_label_dir`
- `val_a_dir`, `val_b_dir`, `val_label_dir`
- `test_a_dir`, `test_b_dir`
- `checkpoint_dir`
- `predict_output_dir`
- `batch_size`
- `epochs`
- `learning_rate`
- `threshold`
- `device`
- `seed`

**Validation Rules**

- Data paths required by the selected workflow must exist.
- `threshold` must be between 0.0 and 1.0 inclusive.
- Numeric training settings must be positive where applicable.
- Output directories may be created if missing.
